# TCG Vault

První jednoduchá homepage pro TCG shop.

## Spuštění

```bash
npm install
npm run dev
```

Pak otevři http://localhost:3000

## Další krok

Až bude vzhled sedět, můžeme přidat:
- skutečné produkty a obrázky
- košík
- objednávkový formulář
- databázi/sklad
- admin
- Discord webhook
- platby
- předobjednávky
